# accordion-plus

Custom **accordion** block. Purpose: expand/collapse items with plus/minus markers and divider rules; Expand All / Collapse All control when there is more than one item.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: title cell (item label) | content cell (paragraphs, sub-labels, lists, links, optional headshot <picture> first). An eyebrow label paragraph authored right before the block is shown in the block heading row, beside Expand All.

## Supported variations

No variations.
