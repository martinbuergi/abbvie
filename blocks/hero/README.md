# hero

Custom **hero** block. Purpose: page-opening hero: full-width photo (optional ambient Brightcove video) with a white overlay card holding the breadcrumb or story back link + meta row, the H1 and the lede.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows classified by content: <picture> poster; optional Brightcove player URL paragraph; <ul> breadcrumb (linked ancestors, current page last) OR a back-link paragraph plus meta paragraphs (date, category, "N Minute Read"); <h1> then the lede paragraph(s).
