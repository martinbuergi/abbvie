# story-cards

Custom **story-cards** block. Purpose: related-story cards: image beside date, category, title, optional description, CTA and reading time; the whole card is the link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: <picture> | date p, category p, title heading, optional description p, story link p (its text is the CTA label), optional reading-time p.

## Supported variations

- `compact-bottom` — 144px below the cards (no grid bottom padding) instead of the default padding + 112px spacer band.
- `side-panel` is set by the block when it sits in a sidebar column; it is not an author option.
