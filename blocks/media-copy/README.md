# media-copy

Custom **media-copy** block. Purpose: image column beside a copy column in the 12-column grid (image leads on mobile).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: image cell (<picture>, optionally with a small heading/text above or below) | copy cell (headings, paragraphs, eyebrow lines, <hr>, CTA links).

## Supported variations

| Variation | Option class |
| --- | --- |
| Wide media column (5-1-6) | `wide-media` |
