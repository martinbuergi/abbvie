# quote

Custom **quote** block. Purpose: pull quote with quote mark, quote text and byline (avatar, name, role).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows classified by content: optional background <picture> row; quote text paragraph(s); byline row (avatar <picture>, name p, role p).

## Supported variations

- `spacing-bottom` — extra space below an in-article (no background) quote: 112px below 744px, 160px from 744px.
